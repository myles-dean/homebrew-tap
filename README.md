# myles-dean/homebrew-tap

Homebrew casks for my apps.

```sh
brew tap myles-dean/tap
brew trust myles-dean/tap
brew install --cask joymouse
brew install --cask dock-folders
```

| Cask | App |
|---|---|
| `joymouse` | [JoyMouse](https://github.com/myles-dean/joymouse): use a Nintendo Switch 2 Joy-Con as a mouse on your Mac |
| `dock-folders` | [Dock Folders](https://github.com/myles-dean/DockFolders): iPhone-style app folders for the macOS Dock |
